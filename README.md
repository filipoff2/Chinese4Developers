# Chinese4Developers

## Colored lessons in Word

[Chinese4Developers-lessons.docx](cloude_fun_fonts/generator/out/Chinese4Developers-lessons.docx) contains all lessons,
with every Chinese character colored by its components. The colors come from a font, so you need to install it first:

1. Download [Hanzi4DevColor4.ttf](cloude_fun_fonts/generator/out/Hanzi4DevColor4.ttf) (on the file page: **Download raw file**).
2. Close Word completely.
3. Right-click the downloaded file and choose **Install**.
4. Download [Chinese4Developers-lessons.docx](cloude_fun_fonts/generator/out/Chinese4Developers-lessons.docx) and open it in Word.

The document uses the font **Hanzi4Dev Color 4**. Without it, Word shows the characters in black.
Hanzi4DevColor1–3 are older builds and are not needed.
GitHub's file preview does not show the colors; open the file in Word.

How the colors work and how to rebuild the font: [cloude_fun_fonts/generator/README.md](cloude_fun_fonts/generator/README.md).
